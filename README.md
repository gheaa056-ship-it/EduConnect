# EduConnect Prototype

Prototype web aplikasi pembelajaran EduConnect.

## Cara menjalankan
Buka index.html dengan Google Chrome, Edge, atau Firefox.

## Fitur
- Dashboard
- Login sederhana
- Kelas pembelajaran
- Materi pembelajaran
- Monitoring progress
- Responsive design

Prototype ini dapat dikembangkan menjadi aplikasi full-stack dengan backend, database, autentikasi, API, dan deployment online.
